<td width="50%" valign="top">

### DocuMind

**Documents → intelligence**

DocuMind explores how AI can make information inside documents easier to **find, understand and interact with**.

Instead of treating a document as something you simply read, the project explores turning it into something you can work with.

**Built with**

`Python` `AI` `Document Processing`

[**VIEW SOURCE →**](https://github.com/Harsh-v01/DocuMind)

</td>

<td width="50%" valign="top">

### Samvad

**Speech → communication**

Samvad is a real-time accessibility platform built around **speech-to-text and text-to-speech**.

The idea is simple: use software to reduce communication barriers between people who communicate differently.

**Built with**

`React` `Firebase` `Speech APIs`

[**VIEW SOURCE →**](https://github.com/Harsh-v01/Samwaad_v02)

</td>

</tr>

<tr>

<td width="50%" valign="top">

### Certify

**Automation → less repetitive work**

Certify focuses on automating certificate generation and verification.

A relatively simple problem that became an opportunity to explore **automation, image processing and verification workflows**.

**Built with**

`Python` `OpenCV` `Automation`

[**VIEW SOURCE →**](https://github.com/Harsh-v01/Certify)

</td>

<td width="50%" valign="top">

### Padh.AI

**Learning → interaction**

Padh.AI explores how AI can make learning experiences more interactive.

The project experiments with combining an educational workflow with intelligent features rather than treating AI as just another chatbot.

**Built with**

`React` `Python` `Firebase`

[**VIEW SOURCE →**](https://github.com/Harsh-v01/Padh.AI)

# `05` — the messy part

Not every repository here started with a perfect plan.

Some started as:

```text
"this would be cool"
```

Some started as:

```text
"can I make this work?"
```

And some started as:

```text
"I have absolutely no idea how this works yet."
```

That's intentional.

I don't want my GitHub to only show finished projects.

I want it to show **the process of getting better at building them.**
